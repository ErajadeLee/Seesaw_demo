# Seesaw Demo v1.1.1

[Download Seesaw Demo for Windows x64](https://github.com/ErajadeLee/Seesaw_demo/archive/refs/heads/main.zip)

1. Download with the link above or **Code > Download ZIP**.
2. Right-click the downloaded ZIP and choose **Extract All** to a writable folder on Windows 10/11 x64.
3. Double-click **Start_Seesaw.cmd**. The first start prepares the included application, then opens the English dashboard.

Python, required libraries and the application are included. No separate Python installation, API key or Internet connection is needed for the included local calculations. Keep all downloaded files together.

Choose your models, observable, input type and units. Supply the requested uncertainty for a measured value. Click **Validate inputs**, then **Run reference inference**. Use **Open result folder** or **Download result JSON** to access results.

Closing the last Seesaw page stops unfinished dashboard calculations and closes the local service after a short delay. Completed results remain saved.

The controlled heavy-mass range is **400-1200 GeV**. Supported Type II/III inclusive production predictions use **13 TeV**. Read the in-app guide for uncertainty requirements and interpretation limits.
